## 项目说明
>原作者地址：[点击跳转](https://bbs.125.la/thread-14818779-1-1.html)
- 一款使用「易语言编写」的QQ头像工具箱。
- 本项目基于原作者开源版本修改，仅供学习参考。

## 支持类型
- 资源类型：JPG、PNG、GIF
- 静态头像：普通头像、半透明头像、全透明头像
- 动态头像「旧」：
    - **电脑QQ怀旧版**显示为动态，**电脑QQNT版本**小概率显示为动态。
	- 工具中使用**上传头像**功能，上传GIF格式图片，即为「旧」动态头像。
- 动态头像「新」：
    - 实则借助**QQ小世界头像**APNG特性，额外添加头像动态图层。
	- 手机QQNT版本，显示头像动态图层，电脑QQNT版本，不显示头像动态图层。
	- 工具中使用**上传动态头像**功能，上传GIF格式图片，即为「新」动态头像。

## 使用说明
- 下载合适的源码版本，使用易语言编译后运行。

## 注意事项
### 易语言
- 由于易语言本体会被杀毒软件误报。
- 使用前先添加白名单或者关闭杀毒软件。
### QQ头像工具箱
>⚠️频繁使用工具箱更换头像会导致账号被封禁。
- 仅支持Windows环境下运行。
- 仅支持**怀旧版**QQKey获取，不支持QQNT版本。
- 获取QQKey时，需使用管理员身份运行工具箱。
